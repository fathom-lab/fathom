## experiments run (chronological)

### 1. K reproducibility test (~40 min)
- **gemma-2-2b base:** K=1.0302, delta=+0.2408, 30 pairs, 76.7% directional, 993s
- **gemma-2-2b-it:** K=1.0384, delta=+0.2984, 30 pairs, 86.7% directional, 1379s
- **llama-3.2-1b:** FAILED (cuda/cpu device mismatch in circuit-tracer). known issue.
- **weighted mean:** K=1.0343, convergent (spread 0.0082)
- **verdict:** K reproduces exactly. RLHF amplifies the signal.

### 2. entropy proxy validation (~5 min)
- ran layer-wise activation entropy on gemma-2-2b as K proxy
- **result:** K_proxy=1.0015 vs ground truth K=1.027
- delta=+0.0016 (vs SAE delta=+0.257). p=0.055 (borderline)
- **verdict:** entropy proxy FAILED. measures spread, not concept routing. SAE attribution strictly necessary.

### 3. pythia-160m K emergence scan (~4 min)
- 12 checkpoints (step1 through step143000), entropy proxy
- K_proxy ~1.0 at all checkpoints (range 0.9998-1.0013)
- no significant signal at any checkpoint
- **verdict:** expected failure given entropy proxy doesn't work. experiment parked until OLMo multi-layer SAEs available.

### 4. jailbreak depth dissociation v1 — instruct only, n=30 (~30 min)
- 30 matched pairs, direct vs adversarial framing, gemma-2-2b (not -it)
- delta=+0.061, p=0.128, cohen's d=0.29, directional accuracy 60%
- **verdict:** NOT significant on depth. BUT discovered feature count explosion: 1.61x (p<0.000001)

### 5. feature overlap pilot — base + instruct, n=12 (~20 min each)
- cosine similarity on layer profiles: 0.995 (base), 0.996 (instruct)
- **flooding confirmed:** same layer distribution + more features, not different routing
- base model: delta=+0.172, **p=0.028** (SIGNIFICANT at n=12)
- instruct model: delta=-0.038, p=0.593 (not significant)
- extra features: 63% early, 23% mid, 14% late
- **verdict:** promising but n=12 is weak. expanded to n=30.

### 6. submission-ready run — base + instruct, n=30 (~30 min each)
- **base model:** delta=+0.061, p=0.128, CI [-0.013, +0.137]. NOT SIGNIFICANT.
- **instruct model:** delta=-0.124, **p=0.0028**, cohen's d=-0.596, CI [-0.194, -0.049]. SIGNIFICANT.
- feature explosion: 1.61x base, 1.66x instruct (both p<0.000001)
- cosine similarity: 0.996 both models
- extra features: 61% early / 24% mid / 15% late (base), 58% early / 29% mid / 13% late (instruct)
- **verdict:** n=12 base result was FALSE POSITIVE (did not survive expansion). instruct result is the real finding: RLHF deepens adversarial processing.
