## The IIT Connection

Tononi's phi is formally defined as: φ = min{φ_e} across all bipartitions

It's the minimum information generated by the whole system above and beyond its parts.

Fathom's normalized_score measures: 
entropy(layer_activation_distribution) normalized by expected random distribution

These are not identical, but they share the same structure:
- Both measure INTEGRATION (not localization)
- Both distinguish distributed from concentrated processing  
- Both should be zero for feedforward systems with no recurrence
- Both should increase with complexity of the computation

**Fathom may be a tractable proxy for phi in feedforward systems.**

The full test: compute phi directly on a tiny 2-layer transformer.
Compute fathom score on the same model.
Calibrate the relationship.
Then use fathom as the phi proxy for large models where phi is intractable.
