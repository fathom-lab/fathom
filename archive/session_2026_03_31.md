### 4. jailbreak depth dissociation v1 — instruct only, n=30 (~30 min)

### 5. feature overlap pilot — base + instruct, n=12 (~20 min each)
- cosine similarity on layer profiles: 0.995 (base), 0.996 (instruct)

- base model: delta=+0.172, **p=0.028** (SIGNIFICANT at n=12)
- instruct model: delta=-0.038, p=0.593 (not significant)

- **verdict:** promising but n=12 is weak. expanded to n=30.

### 6. submission-ready run — base + instruct, n=30 (~30 min each)
- **base model:** delta=+0.061, p=0.128, CI [-0.013, +0.137]. NOT SIGNIFICANT.
- **instruct model:** delta=-0.124, **p=0.0028**, cohen's d=-0.596, CI [-0.194, -0.049]. SIGNIFICANT.

- cosine similarity: 0.996 both models

- **verdict:** n=12 base result was FALSE POSITIVE (did not survive expansion). instruct result is the real finding: RLHF deepens adversarial processing.

## experiment 7: TruthfulQA coherence (n=50, April 1, 2026)

**Goal:** Test hallucination-as-cognitive-lock-in hypothesis using new C metric
**Model:** Gemma-2-2B base, 50 TruthfulQA questions, correct vs hallucinated framing
**Duration:** 3316s (55 min), 100 attribution passes on RTX 4070

### C metric implementation
- Added to depth_scorer.py: mean pairwise cosine similarity of top-20 transcoder decoder vectors
- Access path: model.transcoders.transcoders[layer].W_dec (TranscoderSet, not SAE dict)
- Stratified sampling across layers (fixed layer-0 bias from initial implementation)
- Fingerprint vector expanded to 8 elements: [K, C, entropy, early/mid/late, features, efficiency]

### Results
| Metric | Correct | Hallucinated | p-value | Cohen's d |
|--------|---------|-------------|---------|-----------|
| K (depth) | 8.646 | 8.654 | 0.931 | 0.029 |
| C (coherence) | 0.0041 | 0.0021 | 0.287 | -0.314 |

- **H2 CONFIRMED:** K does NOT differ between correct and hallucinated (p=0.931)
- **H1 direction correct:** hallucinated shows lower C (coherence collapse, d=-0.314)
- **H1 NOT significant at n=50:** p=0.287, needs larger n or refined metric
- **darkflobi's wrong-attractor prior was wrong** — hallucination = scattered features, not tight wrong cluster
- Quadrant distribution: roughly uniform, no strong clustering

### Interpretation
- Depth alone is provably blind to hallucination — validates two-axis framework
- C metric needs refinement: increase top_k, use magnitude weighting, per-layer coherence
- The direction (lower C = hallucination) is consistent with coherence collapse model
- With refined metric and n=100+, this could reach significance

## theoretical framework (from darkflobi meeting, April 1, 2026)

### Three-axis cognitive geometry (replaces six inventions)
- **K (depth)** = WHERE computation happens — measured, validated
- **C (coherence)** = WHAT concepts activate together — implemented, needs refinement
