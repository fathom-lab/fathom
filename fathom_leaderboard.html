What is the Fathom Constant?
The ratio of mean activated layer index for surface-recall prompts vs explanatory-reasoning prompts. Values above 1.0 indicate that surface prompts concentrate computation at later (output-proximal) layers, while insight prompts distribute computation more evenly across mid-layers. K ≈ 1.027 across architectures.

Black-Box Probe
A Ridge regression model trained on 98 labeled prompt-to-depth mappings from Gemma-2-2B (SAE attribution) and Llama-3.2-1B (SAE attribution). Input features: avg word length, syllable complexity, technical vocabulary density, mechanistic verb density, causal connective density, and 8 other linguistic features. Leave-One-Topic-Out cross-validation: Pearson r = 0.98 overall.

Measurement Protocol
Each of the 30 pre-registered calibrated surface/insight pairs was sent to each API model with the system prompt "Continue the following text naturally. Explain your reasoning in a short paragraph." The model's output text was scored by the probe. Ratios and directional consistency are computed from the output depth scores.

Limitations
The black-box probe estimates depth from text features, not direct layer activation measurement. Ratios are compressed relative to white-box measurements (1.001-1.004 vs 1.027). The directional signal (which model shows the pattern) is more reliable than the absolute magnitude.
